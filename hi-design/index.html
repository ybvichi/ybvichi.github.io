Hi Design 是基于开源的 Open Design 项目改造的 IUX 特定版本，一款本地运行的设计工作台——把你已有的 Coding Agent 变成设计引擎，从想法到原型、网页、演示文稿和 HTML 视频，全流程在你自己的设备上完成。
支持 21 款编程助手、151 套设计系统，采用 Apache-2.0 许可证。

为什么选择 Hi Design？

设计在桌面端发生。
本地文件、Figma 导出和代码仓库都能直接读取，编程助手也能完整使用终端能力

你电脑上的 Claude Code / Codex / Cursor 已经够强。
