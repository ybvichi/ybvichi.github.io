1如何安装

选择适合您平台的安装包，几分钟即可完成安装

  1. 进入首页

    打开 Hi Design 首页，页面会自动识别您的操作系统，显示对应的下载按钮。

    Windows 用户将看到「下载桌面端 · Windows」按钮；macOS 用户将看到「下载桌面端 · macOS」按钮。

  2. 点击下载

    确认显示的版本与您的系统一致后，点击下载按钮即可开始下载。

    Windows 用户会得到 .exe 安装文件；macOS 用户会得到 .dmg 磁盘映像文件。

  3. 运行安装

    双击下载的文件，按照安装向导提示完成安装。

    Windows：双击 .exe 文件运行安装向导。如果系统提示"Windows 已保护您的电脑"，请点击"更多信息" → “仍要运行"。

    macOS：双击 .dmg 文件挂载磁盘映像，然后将 Hi Design 应用拖拽到 Applications 文件夹中。

  4. 启动应用

    安装完成后，在开始菜单（Windows）或 Applications 文件夹（macOS）中找到 Hi Design，双击即可启动。

    首次启动后，您可以开始创建设计项目或选择设计系统进行设计。

2如何配置本地 CLI

在 Web 界面中选择并配置本地命令行代理工具，让 Hi Design 通过你本机安装的 CLI 执行设计任务

  1. 打开本地 CLI 配置面板

    在 Hi Design 首页的右上角，找到「本地 CLI」按钮并点击，打开配置面板。

    「本地 CLI」按钮位于页面右上角，显示当前已选择的代理名称。初始状态显示「本地 CLI·未选择·默认」，配置成功后显示具体的代理名称（如「本地 CLI·Claude Code·Sonnet」）。

  2. 选择执行模式

    点击「本地 CLI」按钮后，会弹出一个下拉面板，顶部显示两种执行模式：

    • 本地 CLI：使用本机安装的命令行工具运行提示词
    • 自带 Key：使用自己的 API Key 直接调用模型

    选择「本地 CLI」模式后，系统会自动扫描 PATH 中可用的 CLI 工具。

    如果 PATH 中未发现可用的 CLI，面板会显示「PATH 中未发现可用 CLI」。此时可以点击「打开执行设置」进入详细的配置页面。

  3. 进入执行设置页面

    点击下拉面板底部的「打开执行设置」，进入详细的执行模式设置弹窗。

    执行设置页面分为左右两部分：

    • 左侧菜单：包含执行模式、指令/规则、记忆、媒体生成提供商、外部 MCP、连接器、MCP 服务器、界面语言、外观、设计评审团、通知、宠物、设计系统、项目位置、隐私、关于等设置项
    • 右侧内容：显示当前选中设置项的详细配置

  4. 选择代理工具

    在「执行模式」页面的「你的 CLI」区域，可以看到系统已扫描到的本地 CLI 工具列表。每个 CLI 卡片显示：

    • 名称与图标：如 Claude Code、Codex CLI、GitHub Copilot CLI 等
    • 描述：CLI 的来源说明，如「Anthropic official CLI」
    • 版本：已安装的 CLI 版本号
    • 模型：当前使用的模型配置，默认显示「Default (CLI config)」

    点击想要使用的 CLI 卡片即可选中该代理工具。

    Hi Design 支持多种本地 CLI 代理，包括 Claude Code（Anthropic 官方）、Codex CLI（OpenAI 官方）、GitHub Copilot CLI（GitHub 官方）等。如果 PATH 中未发现可用的 CLI，请确保已安装对应的 CLI 工具并将其添加到系统 PATH 中。

  5. 安装更多 CLI（可选）

    在「你的 CLI」列表下方，点击「可安装」展开区域，可以看到更多可安装的 CLI 工具列表（共 21 个）。每个条目显示：

    • CLI 名称：如 Devin for Terminal、OpenCode、Hermes、Trae CLI 等
    • 描述：CLI 的简要说明
    • 安装状态：显示「安装」按钮或「已安装」状态

    点击「安装」按钮，按照提示完成对应 CLI 的安装。安装完成后，点击「重新扫描」按钮刷新列表。

  6. 重新扫描 CLI

    如果安装或卸载了 CLI 工具，可以点击「你的 CLI」区域右上角的「重新扫描」按钮，让 Hi Design 重新扫描 PATH 中的可用 CLI。

    如果你通过 npm 或 Homebrew 安装了 CLI，但仍显示为未安装，请确认该工具的 bin 目录已加入 Hi Design daemon 继承的 PATH（在 macOS 上，Terminal 与 GUI 应用的 PATH 可能不同）。请参阅 QUICKSTART.md（「Local agent CLI and PATH」章节）。

  7. 验证配置

    配置完成后，关闭设置弹窗返回首页。确认右上角「本地 CLI」按钮显示你选择的代理名称（如「本地 CLI·Claude Code·Sonnet」），表示配置已成功生效。

    此时你可以在输入框中输入提示词，点击「发送」按钮，Hi Design 将通过你配置的本地 CLI 工具执行设计任务。

💡 常见问题

Q: 为什么 PATH 中未发现可用 CLI？

A: 请确保已安装对应的 CLI 工具（如 claude、codex 等），并且已将其添加到系统 PATH 环境变量中。安装后需要点击「重新扫描」按钮刷新列表。在 macOS 上，Terminal 与 GUI 应用的 PATH 可能不同，需要特别注意。

Q: 如何切换回默认代理？

A: 重新打开本地 CLI 配置面板，在「你的 CLI」列表中选择其他代理工具即可。或者切换到「自带 Key」模式，使用自己的 API Key 直接调用模型。

Q: 安装了 CLI 但扫描不到怎么办？

A: 请按照以下步骤排查：1）在目标代理卡片上打开「安装」或「文档」链接；2）返回 Hi Design 之前，请先在对应 CLI 中完成认证（登录或添加 API 凭据）；3）在此区域点击「重新扫描」；4）当代理显示为已安装后，选择该代理卡片。

3如何选择设计系统进行设计

了解 Hi Design 内置的设计系统，选择适合您项目的视觉规范。默认使用 HUI 设计系统，开箱即用

  1. 了解默认设计系统 — HUI

    Hi Design 默认使用 HUI 设计系统，由海康 HUI 设计 token 整理而成。首次打开 Hi Design 时，无需任何操作，系统已自动采用 HUI 作为默认设计系统。

    HUI 设计系统的特点：

    • 双层 token 结构：上层是 56 个 Open Design 契约 token（供通用组件与跨品牌切换），下层是完整的 HUI 原生 token
    • 浅色主题：默认提供浅色主题的设计 token，适合大多数设计场景
    • 字体排版：包含 h-icon 等字体样式，统一视觉风格
    HUI 是 Hi Design 的官方推荐设计系统，适合大多数设计场景。如果您没有特殊需求，直接使用默认的 HUI 即可，无需额外配置。

  2. 打开设计系统选择器

    如果需要切换设计系统，在 Hi Design 首页的输入框下方，找到设计系统按钮（默认显示「HUI」）并点击，打开设计系统选择面板。

    设计系统按钮位于输入框下方，默认显示「HUI」。点击后会弹出设计系统选择面板，展示所有可用的设计系统列表。

  3. 浏览设计系统列表

    点击后会弹出设计系统选择面板，面板分为左右两部分：

    • 左侧列表：显示所有可用的设计系统名称，包括「不指定设计系统」和「官方预设」分类下的各种设计系统（如 Neutral Modern、Agentic、Airbnb、Airtable、Apple 等）
    • 右侧预览：显示当前选中设计系统的详细信息，包括品牌标识、字体排版、调色板等视觉预览
    设计系统选择面板加载后，默认展示 HUI 设计系统的预览信息。将鼠标悬停在左侧任意设计系统名称上，右侧会实时显示该设计系统的预览信息。

  4. 预览设计系统详情

    将鼠标悬停在左侧的设计系统名称上，右侧预览区域会显示该设计系统的详细信息：

    • 品牌标识：设计系统的简介和特点说明
    • 字体排版：显示该设计系统使用的字体样式（如 Display、Body、Mono 等）
    • 调色板：展示设计系统的主色调和配色方案
    预览信息帮助您了解每个设计系统的视觉风格，方便选择最适合项目需求的设计系统。例如，Neutral Modern 是「A clean, product-oriented default」，适合 B2B 工具、仪表盘和工具页面。

  5. 搜索并选择设计系统

    如果设计系统列表较长，可以使用面板顶部的搜索框快速查找。输入关键词（如「HUI」），列表会实时过滤匹配的设计系统。

    在列表中找到想要使用的设计系统，点击即可选中。选中后，面板底部的按钮会显示「打开预览」，点击可以查看更详细的设计系统预览。

    搜索框支持实时搜索，输入关键词后会自动过滤列表。点击「清除」按钮可以清空搜索内容，恢复显示全部设计系统。

  6. 创建自定义设计系统（可选）

    如果内置的设计系统无法满足需求，可以点击面板右上角的「创建」按钮，创建自定义设计系统。

    创建设计系统需要三个步骤：

    • Website or DESIGN.md：粘贴链接、选择品牌或复制 token
    • Add material：添加图片、字体、repo 或 .fig 文件（可选）
    • Generate：快速提取设计系统，AI 后续可继续细化

    您也可以通过 GitHub 仓库、网站、DESIGN.md 或能体现风格的文件开始创建。Hi Design 会先快速创建一套可用系统，然后 AI 可在项目中继续细化。

    创建自定义设计系统需要一定的设计基础。如果您是初次使用，建议先使用默认的 HUI 设计系统熟悉流程，再尝试创建自定义设计系统。

  7. 验证设计系统选择

    选择设计系统后，关闭选择面板返回首页。确认输入框下方的设计系统按钮显示您选择的名称（如「HUI」），表示设计系统已成功切换。

    此时您在输入框中输入提示词并发送，Hi Design 将使用您选择的设计系统的视觉规范来生成设计。

💡 常见问题

Q: 默认使用的是什么设计系统？

A: Hi Design 默认使用 HUI 设计系统，由海康 HUI 设计 token 整理而成。首次打开应用时无需任何配置，系统已自动采用 HUI 作为默认设计系统。如果您没有特殊需求，直接使用默认设置即可。

Q: 设计系统选择面板加载很慢怎么办？

A: 设计系统列表需要从服务器加载，请确保网络连接正常。如果加载时间过长，可以尝试刷新页面或检查网络连接。

Q: 如何切换回默认设计系统？

A: 重新打开设计系统选择面板，选择「HUI」即可切换回默认设计系统。或者选择「不指定设计系统」来使用系统默认设置。

Q: 自定义设计系统可以分享给团队成员吗？

A: 可以。创建的设计系统会保存在您的账户中，团队成员可以在设计系统列表中看到并使用。

4如何选择 Skill 技能进行设计

掌握 Skill 技能的选择与使用，让 AI 按照特定能力执行设计任务

  1. 在输入框中输入 "@" 触发技能选择面板

    在 Hi Design 首页的输入框中，输入 "@" 符号，系统会自动弹出技能选择面板。

    技能选择面板顶部显示多个分类标签：

    • 全部：显示所有可用的技能和插件（共 743 个）
    • 设计文件：设计相关的文件和模板
    • 插件：可扩展功能的插件（459 个）
    • 技能：AI 执行设计任务的技能（284 个）
    • MCP：模型上下文协议相关的工具
    • Connectors：外部系统连接器
    输入 "@" 后，技能选择面板会自动弹出。如果面板没有自动出现，请确保输入框已获得焦点。

  2. 切换到「技能」标签并选择技能

    在技能选择面板中，点击「技能」标签，切换到技能列表视图。这里展示了所有可用的 AI 技能，每个技能卡片显示：

    • 技能名称：如「3D动画男孩搭建Lego」、「Agentic」、「Airbnb」等
    • 技能描述：简要说明该技能的功能和用途
    • 来源标识：显示「Official」表示官方技能

    在技能列表中，点击想要使用的技能条目，该技能会被插入到输入框中。然后您可以继续输入设计需求，AI 将按照该技能的能力来执行设计任务。

    技能列表包含 284 个技能，涵盖了从 3D 动画、平面设计到数据分析等各种设计场景。您可以根据项目需求选择合适的技能。

  3. 通过左侧「集成」菜单浏览技能（可选）

    除了通过 "@" 触发技能选择面板外，您还可以通过左侧导航菜单来浏览和管理技能：

    1. 点击左上角的菜单按钮（或按快捷键）打开左侧导航栏
    2. 在导航栏中找到并点击「集成」菜单
    3. 在「集成」页面中，切换到「技能」标签
    4. 浏览所有可用的技能，并可以查看已安装的技能列表
    通过「集成」菜单，您可以更全面地管理技能，包括查看技能详情、安装新技能、卸载不需要的技能等。

  4. 新建自定义技能（可选）

    如果内置的技能无法满足您的需求，您可以创建自定义技能。在「集成」>「技能」页面中，点击「新建技能」按钮，按照提示创建属于您自己的技能。

    创建自定义技能需要：

    • 技能名称：为您的技能命名
    • 技能描述：说明该技能的功能和用途
    • 技能配置：定义技能的触发条件和执行逻辑
    创建自定义技能需要一定的技术基础。如果您是初次使用，建议先熟悉内置技能的使用方法，再尝试创建自定义技能。

💡 常见问题

Q: 输入 "@" 后没有弹出技能选择面板怎么办？

A: 请确保输入框已获得焦点（点击输入框后再输入 "@"）。如果仍然没有弹出，尝试刷新页面后重试。

Q: 可以同时使用多个技能吗？

A: 是的，您可以在输入框中选择多个技能，AI 会综合这些技能的能力来执行设计任务。

Q: 自定义技能可以分享给团队成员吗？

A: 可以。创建的自定义技能会保存在您的账户中，团队成员可以在技能列表中看到并使用。

5如何分享生成的设计文件

将您的设计成果通过链接分享给团队成员或合作伙伴，方便协作与审阅

  1. 打开设计文件

    在 Hi Design 中完成设计后，确保当前正在查看您想要分享的设计文件。设计文件会在右侧的预览区域中显示。

    分享功能适用于所有已生成的设计文件，包括 HTML 页面、图片、视频等。确保文件已正确渲染后再进行分享。

  2. 点击「分享」按钮

    在页面右上方的工具栏中，找到「分享」按钮并点击。分享按钮位于「推送」按钮左侧，图标为一个向外分享的箭头。

    点击后会弹出一个下拉菜单，提供两个分享选项：

    • 复制分享链接：生成一个可分享的链接，复制到剪贴板，方便通过邮件、即时通讯工具等发送给他人
    • 分享到项目广场：将设计文件发布到项目广场，供更多用户浏览和参考
    「复制分享链接」是最常用的分享方式，适合需要私下分享给特定人员或团队的场景。「分享到项目广场」则适合展示优秀作品或寻求社区反馈。

  3. 复制分享链接

    点击「复制分享链接」选项，系统会自动生成一个分享链接并将其复制到您的剪贴板。

    复制成功后，页面顶部会显示「复制链接成功」的提示，表示链接已准备好可以粘贴分享。

    分享链接包含当前设计文件的完整访问路径，接收者打开链接即可查看设计内容，无需登录或额外权限。请妥善保管分享链接，避免泄露给非授权人员。

  4. 粘贴并分享链接

    将复制的链接粘贴到您想要分享的渠道中：

    • 即时通讯：微信、钉钉、飞书、Slack 等，直接粘贴链接发送给同事
    • 邮件：在邮件正文中粘贴链接，方便收件人点击查看
    • 文档：嵌入到设计文档、需求文档或会议纪要中
    • 项目管理工具：Jira、Notion、Trello 等任务或文档中附加链接
    接收者点击链接后，将直接打开设计文件的预览页面，可以查看完整的设计效果。如果设计文件包含交互元素，接收者也可以正常体验交互效果。

💡 常见问题

Q: 分享链接的有效期是多久？

A: 分享链接默认长期有效。只要设计文件未被删除或项目未被移除，链接就可以一直访问。如果您需要撤销分享，可以联系管理员处理。

Q: 分享后其他人可以编辑我的设计吗？

A: 通过「复制分享链接」分享的设计文件，接收者只能查看，无法编辑。如果您需要协作编辑，请使用项目内的协作功能或邀请团队成员加入项目。

Q: 为什么点击分享后没有反应？

A: 请确保当前页面已完全加载，且您正在查看一个已生成的设计文件。如果问题持续，尝试刷新页面后重试。

Q: 可以分享到项目广场后撤回吗？

A: 分享到项目广场的内容通常需要管理员审核。如需撤回，请联系项目管理员或支持团队处理。

6如何推送到 Pixso 进行微调

将设计文件一键推送到 Pixso，在 Pixso 中使用 AI Builder Dev 插件进行进一步的协作与微调

  1. 确保 Pixso 中已打开 AI Builder Dev 插件

    在推送之前，请确保您已在 Pixso 中安装并打开了 AI Builder Dev 插件。这是接收 Hi Design 推送内容的必要条件。

    如果尚未安装 AI Builder Dev 插件，请先在 Pixso 的插件市场中搜索并安装。安装完成后，在 Pixso 编辑器中打开该插件，确保其处于就绪状态。

  2. 打开设计文件

    在 Hi Design 中完成设计后，确保当前正在查看您想要推送到 Pixso 的设计文件。设计文件会在右侧的预览区域中显示。

    推送功能适用于所有已生成的设计文件。确保文件已正确渲染，并且是您想要推送到 Pixso 的最终版本。

  3. 点击「推送」按钮

    在页面右上方的工具栏中，找到「推送」按钮并点击。推送按钮位于「分享」按钮右侧，图标为一个向上的箭头。

    点击后会弹出一个下拉菜单，显示「推送到 Pixso」选项，并附带提示「请确保 Pixso 中已打开 AI Builder Dev 插件」。

    「推送」功能将当前设计文件发送到 Pixso 平台，方便您在 Pixso 中使用专业的设计工具进行进一步的编辑和微调。与「分享」不同，推送是将文件传输到另一个设计平台，而不是生成可分享的链接。

  4. 选择「推送到 Pixso」

    在下拉菜单中点击「推送到 Pixso」选项，系统会立即开始将设计文件推送到 Pixso。

    推送成功后，页面顶部会显示「已推送到 Pixso」的成功提示，表示文件已成功传输到 Pixso 平台。

    推送过程通常很快，取决于设计文件的复杂程度和网络状况。如果文件包含大量图片或复杂布局，推送可能需要稍长时间。

  5. 在 Pixso 中进行微调

    推送完成后，切换到 Pixso 编辑器，您会在 AI Builder Dev 插件中看到从 Hi Design 推送过来的设计文件。

    在 Pixso 中，您可以对设计进行以下微调操作：

    • 调整布局：修改元素的位置、大小和对齐方式
    • 编辑样式：调整颜色、字体、间距等视觉样式
    • 添加交互：为设计添加原型交互和动画效果
    • 组件化管理：将设计元素转换为可复用的组件
    • 导出资源：导出设计稿为图片、SVG 或其他格式
    Pixso 是一款专业的设计协作工具，提供了比 Hi Design 更精细的设计编辑能力。建议在 Hi Design 中完成设计初稿后，推送到 Pixso 进行细节打磨和团队协作。

💡 常见问题

Q: 推送失败怎么办？

A: 请检查以下几点：1）确保 Pixso 中已打开 AI Builder Dev 插件；2）检查网络连接是否正常；3）确认 Pixso 账号已登录且有权限接收推送内容。如果问题持续，尝试重新打开 Pixso 插件后重试。

Q: 推送到 Pixso 后，Hi Design 中的设计会更新吗？

A: 不会。推送是单向传输，从 Hi Design 到 Pixso。在 Pixso 中的修改不会自动同步回 Hi Design。如果您需要在 Hi Design 中继续迭代，建议保留原始设计文件，在 Pixso 中完成微调后手动将修改内容反馈到 Hi Design。

Q: 可以推送哪些类型的设计文件到 Pixso？

A: 目前支持推送 HTML 页面设计到 Pixso。包括网页布局、UI 界面、营销页面等。复杂的交互式组件和动画效果在 Pixso 中可能需要重新实现。

Q: 推送到 Pixso 后，其他团队成员可以看到吗？

A: 这取决于您的 Pixso 项目权限设置。如果 Pixso 项目是公开的或团队成员有访问权限，他们可以在 AI Builder Dev 插件中看到推送的设计文件。请确保在 Pixso 中正确设置项目权限。
